# Security Policy

## Scope

Security reports should focus on:

- Exposed credentials or secrets
- Vulnerable application behavior
- Unsafe dependency or workflow configuration
- Issues that could compromise the deployed Streamlit application

## Reporting

Please do not publish sensitive security details in a public issue.

Contact the repository owner through:

https://github.com/mightyalok00

Include a short description, reproduction steps, potential impact, and a minimal proof of concept when safe.

Do not include real credentials, tokens or other secrets in a report.

## Secrets

The project is designed to run without application API keys. Never commit credentials to the repository.
